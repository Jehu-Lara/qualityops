# Roadmap

Progress is gated by evidence, not by the number of technologies added.

| Stage | Deliverable | Acceptance evidence | Status |
|---|---|---|---|
| Statistical core | Overall `Pp/Ppk` and explicit-sigma `Cp/Cpk` | analytical tests pass | Complete |
| Data ingestion | strict `.xlsx` measurement extraction | invalid inputs fail visibly | Complete |
| Minitab validation | same-data comparison | completed validation record within tolerance | Complete |
| External data | dataset not generated by the author | provenance and data-quality log | Planned |
| Data persistence | PostgreSQL schema | constraints, migrations, and 20 useful queries | Planned |
| Decision view | one-page Power BI Process Health report | decision-focused demonstration | Planned |
| Service interface | small FastAPI surface | tested request/response contract | Planned |
| Reproducibility | Docker image | successful clean-machine run | Planned |
| AI interpretation | evidence-linked explanation layer | expert rubric and failure-case evaluation | Deferred |

## Non-goals for the current release

- RAG, agents, LangGraph, MCP, or model fine-tuning;
- automatic causal conclusions;
- production MES/QMS/ERP integration;
- undocumented estimation of within-subgroup variation.
