# Python–Minitab validation protocol

## Objective

Demonstrate that Python and Minitab reproduce the same selected metrics when they receive the same data and statistical assumptions.

## Required controls

Record all of the following before comparing outputs:

1. safe dataset identifier and worksheet;
2. measurement column and observation count;
3. excluded rows and missing-value rule;
4. LSL and USL, including units;
5. subgroup definition and ordering;
6. Minitab analysis and standard-deviation method;
7. unrounded outputs and software versions.

Do not publish confidential measurements, operator identities, customer information, or internal file paths.

## Track A — overall performance

QualityOps calculates the ordinary overall sample standard deviation with denominator `n - 1`. Validate these fields against Minitab's **overall** results:

- count;
- mean;
- overall standard deviation;
- `Pp`;
- `Ppk`.

Example Python run:

```bash
qualityops analyze \
  --file data/measurements.xlsx \
  --column measurement \
  --lsl <LSL> \
  --usl <USL>
```

Minitab documents that its overall standard deviation supports `Pp/Ppk`, while its within-subgroup standard deviation supports `Cp/Cpk` ([process-data reference](https://support.minitab.com/en-us/minitab/help-and-how-to/quality-and-process-improvement/capability-analysis/how-to/capability-analysis/normal-capability-analysis/interpret-the-results/all-statistics-and-graphs/process-data/)).

## Track B — potential capability

Do not validate `Cp/Cpk` by substituting overall sample standard deviation. First record the within-subgroup sigma generated by the intended Minitab method. Then supply that exact unrounded value:

```bash
qualityops analyze \
  --file data/measurements.xlsx \
  --column measurement \
  --lsl <LSL> \
  --usl <USL> \
  --within-sigma <UNROUNDED_WITHIN_SIGMA>
```

This release validates the index formulas after sigma estimation; it does not reproduce Minitab's pooled, moving-range, `Rbar`, `Sbar`, or MSSD estimator internally.

## Numerical acceptance rule

Use unrounded exported values and evaluate each comparison with:

```text
absolute_difference <= 1e-9
```

If the Minitab report exposes fewer decimal places, increase the displayed precision or export the result before evaluating the tolerance. A rounded screenshot alone is insufficient evidence for a `1e-9` comparison.

## Interpretation gate

Numerical agreement confirms implementation reproducibility only. Before treating capability metrics as decision evidence, separately assess:

- statistical control and time ordering;
- distribution fit or a justified nonnormal method;
- rational subgrouping;
- measurement-system adequacy;
- representativeness of the observation window.
